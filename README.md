# 🎰 Casino Royale (No Money)

**Демо-проект: браузерное мини-казино на чистом JavaScript, CSS и HTML.**

Азарт без регистрации и без реальных денег. Симулятор управления рисками для портфолио: работа с состоянием, анимации, звуки, математика вероятностей, модальные окна и сохранение прогресса.

---

| Параметр | Значение |
|---|---|
| **Название** | Casino Royale (No Money) |
| **Валюта** | Фишки (🪙) |

## 🎲 Игры

### 1. Кости (Craps / 2 кубика)

- Игрок выбирает сумму от **2 до 12**
- Два кубика с CSS-анимацией подбрасывания
- Выплаты от **x5** (сумма 7) до **x30** (суммы 2 и 12)

| Сумма | Вероятность | Множитель |
|---|---|---|
| 2 или 12 | 1/36 (2.8%) | x30 |
| 3 или 11 | 2/36 (5.6%) | x15 |
| 4 или 10 | 3/36 (8.3%) | x10 |
| 5 или 9 | 4/36 (11.1%) | x7 |
| 6 или 8 | 5/36 (13.9%) | x6 |
| 7 | 6/36 (16.7%) | x5 |

### 2. Рулетка (Европейская)

- Поле **0–36** (18 красных, 18 чёрных, 1 зелёный)
- Визуальное вращающееся колесо (Canvas + CSS transform)
- Виды ставок:

| Ставка | Описание | Выплата |
|---|---|---|
| Число | Конкретное число (0–36) | x36 |
| Красное / Чёрное | Цвет сектора | x2 |
| Чёт / Нечёт | Чётность числа | x2 |
| Дюжина (1-12, 13-24, 25-36) | Диапазон чисел | x3 |

- Анимация: 5–7 полных оборотов с замедлением (`cubic-bezier`)
- Математика: угол поворота = `(37 - result) × sectorAngle - offset`

### 3. Слот-машина (3 барабана)

- 6 символов: 🍒 🍋 🔔 7️⃣ ⭐ 💎
- Каскадная остановка барабанов (слева направо)
- Выплаты:

| Комбинация | Множитель |
|---|---|
| 🍒🍒🍒 / 🍋🍋🍋 / 🔔🔔🔔 / ⭐⭐⭐ / 💎💎💎 | x5 |
| 7️⃣7️⃣7️⃣ | x20 |
| Два любых одинаковых | x1 (возврат ставки) |

## 🎨 Визуальные эффекты

- **Неоновая тема**: чёрный фон + золотые акценты (`#ffd700`)
- **Шрифты**: Orbitron (заголовки) + Inter (текст) — Google Fonts
- **Конфетти**: CSS-анимация 60 частиц при крупном выигрыше (x10+)
- **Тост-уведомления**: всплывающие сообщения о выигрышах/проигрышах
- **Анимации**:
  - Вращение колеса рулетки (CSS transition, 4 секунды)
  - Подбрасывание кубиков (CSS keyframes, 0.6 сек)
  - Прокрутка слотов (setInterval + каскадная остановка)
- **Адаптив**: сетка Flex/Grid, поддержка мобильных устройств

|---|---|

| Выигрыш | Восходящие три ноты (C E G) |
| Джекпот | Четыре ноты с финальным аккордом |
| Проигрыш | Нисходящие низкие тона |

## 💾 Сохранение

- **Баланс** — сохраняется в `localStorage` после каждой ставки
- **Рекорд** — наибольший баланс за всю историю
- **Сброс** — кнопка возвращает 1 000 фишек

```js
// Ключи localStorage
cr_balance  → текущий баланс
cr_record   → рекордный баланс
```

---

## 🎮 Управление

- **Переключение игр**: вкладки в верхней панели
- **Авто-режим**: кнопка «Авто x10» — 10 раундов подряд по той же ставке (с задержкой)
- **Сброс**: кнопка в футере — сброс до 1 000 фишек
- Ставка не может превышать текущий баланс

## 🧠 Математика вероятностей

### Рулетка (европейская, 37 секторов)

| Ставка | P(win) | Выплата | EV (отн. ставки) |
|---|---|---|---|
| Число | 1/37 ≈ 2.70% | x36 | 36/37 ≈ 97.3% |
| Красное/Чёрное | 18/37 ≈ 48.65% | x2 | 36/37 ≈ 97.3% |
| Дюжина | 12/37 ≈ 32.43% | x3 | 36/37 ≈ 97.3% |
| Чёт/Нечёт | 18/37 ≈ 48.65% | x2 | 36/37 ≈ 97.3% |

**Преимущество казино**: 2.7% (стандарт для европейской рулетки)

### Кости

Математическое ожидание зависит от выбранной суммы. Среднее EV по всем ставкам: **~83.3%** (преимущество казино ~16.7%).

### Слоты

- Джекпот (3 одинаковых): ≈ 2.8% (с учётом 6 символов)
- Два совпадения: ≈ 41.7%
- Полный проигрыш: ≈ 55.5%

## ⚙️ Запуск
